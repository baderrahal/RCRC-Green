Step 1 with its search box, pull request 94

This is a mockup, not a screenshot. It is drawn by hand from DrawingSheetPanel.cs, PlotTickList.cs and PanelSteps.cs so the layout and the wording can be read before someone spends an install on it. It cannot show how Revit will really render the panel, how the WPF controls space themselves, how tall the bounded list comes out, or how the theme colours look on a real monitor.

Everything in the panels below comes from the code: the words from PanelSteps, the stems from SheetNumberRun.StemOf, the range ends from PlotTickList.RangeEnds and the counts from PlotTickList.

Four things changed here this round. Ticking a plot no longer folds the step and opens step 2. From and To hold the digits 01 to 99 on every model rather than the sub plots the open one happens to hold. Each ticked plot has a search box with All and None over what it shows, and its sub plot lines sit in a bounded list that scrolls inside itself, so the plot lines and the steps below stay in view. Each line says what its sheet numbers will be built from, labelled, where it used to read DM-02DM02.

What the search does and does not do

DM is showing a search of 4, so its list holds DM-41 to DM-45 and hides nothing else, because every DM sub plot in this model matches. All and None act on exactly what is showing, never on what the filter has hidden, which is the rule BulkMarking already follows for the grid. The count line below counts ticks rather than lines, so it does not move when somebody types in a search box.

The range and the list are two different things

DM runs 01 to 99 and FP runs 01 to 20, and both lists hold only the sub plots this model really carries inside those ranges. The count line says both numbers: the ranges cover 119 numbers and the model holds 7 of them. A range set up for a model that is not open yet lists nothing and still shows what was picked.

The shut step

With step 1 shut its header reads 1  PLOTS   DM, FP, 6 of 7 sub plots ticked, and before anything is ticked it reads 160 in the model, none ticked. Ticking a plot opens no other step now. Next at the foot of the step is the only way on.
