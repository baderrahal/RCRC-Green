The progress window while a press runs

Modeless and owned by the Revit main window, so it stays over Revit rather than over everything on the machine. It shows the same words the status line shows, out of ProgressWords. It is opened by the pane before the external event is raised and closed when the run's last answer comes back, never from inside Execute. There is no Cancel: cancelling mid read would leave a half read set of plots the reconciliation would count as read.
