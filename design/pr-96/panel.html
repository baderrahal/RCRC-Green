The grid with four states, pull request 96

This is a mockup, not a screenshot. It is drawn by hand from DrawingSheetPanel.cs, SheetGrid.cs and PanelSteps.cs so the layout and the wording can be read before someone spends an install on it. It cannot show how Revit will really render the panel, how wide the columns come out once a sheet number sits under each square, or how the theme colours look on a real monitor.

Every word below comes from the code: the four states from SheetCellState, the squares and their numbers from SheetGridCell, and the tooltip and legend wording from PanelSteps.CellInWords and LegendInWords.

A cell had three states and no number. A view already drawn on a sheet and a view nobody has placed looked the same, so the grid could not say which sub plots are running on copy numbers. DM-11 below is the one sub plot on the real model with real numbers. DM-12 is on copies, DM-13 has its views on no sheet at all, and DM-14 has nothing yet, with two squares marked to be made.

Bulk marking was already there

The round asked for it as something never built. All four are wired and tested and this pull request rebuilds none of them: the sub plot name marks its row, the column header marks its column, and the two buttons above the grid are Mark every missing and Clear all marks. What changed is that the rules file now records where they are, so the next round checks before writing a second copy.
