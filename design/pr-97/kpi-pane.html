A run with no link loaded says so before the press

The only pane change in this pull request is one line, added to TheCreateButton after the refusal line and before everything else in the block. It comes off KpiPlotFacts.Links, which the plot read fills from the host document's own link instances, so it is on screen as soon as the pane has read the model and long before anybody presses anything.
