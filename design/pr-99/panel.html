What each mark on a card means

on the cardwhat it sayswhere it comes from

Where every position comes from

The panel decides one number, how many pixels a foot is. Everything else is read off the same object the writer places from.

the runthe preview
SheetPlacement.Of(area, viewsPerSheet, views)
ModelWriter.PlaceOnOneSheet reads PlacedView.Spot and hands it to Viewport.Create DrawingSheetPanel.Drawn reads the same Spot and sets Canvas.Left and Canvas.Top

Revit counts Y up from the bottom of the sheet and a Canvas counts down from the top, so the card takes the centre off the height rather than adding it to nothing. That is the only arithmetic on the drawing side.
