Drawing Sheet panel layout

This is a mockup drawn by hand from the code in src/RcrcGreen.Revit/DrawingSheetPanel.cs. It is not a screenshot.

Nothing on this page has been rendered by Revit or by WPF. It cannot show how Revit's theme will paint the panel, how the Windows control chrome will look on the dark theme, what the real fonts and spacing come out as, or whether the box characters in the grid have a glyph in the font Revit uses.

It exists so the layout and the wording can be read before someone spends an install on it. If anyone ever describes it as a screenshot, it has stopped being worth having.

What changed from pull request 11

  • Nothing is ticked when the panel first reads the model. 84 types all on was a grid too wide to read.
  • A Search box above the list, filtering on the code and on the name as the user types.
  • All and None act on what the search is showing, not on the whole 84.
  • One button per code in use. Pressing 600 ticks every 600 type and leaves the rest.
  • An Add row under the list. The code comes from a list of codes the model uses, the name is free text. An added type is ticked, marked new, and shows missing on every plot.
  • The count now reads ticked out of total and says how many the search is showing. The list and the count are drawn from one place, so they cannot disagree.
  • Schedule columns are marked and set in italics, because a schedule is built by a different call and filters on a different parameter from a plan view.
  • A RUN section, saying what it would make before anything is pressed.

What this page cannot tell you

  • Whether any of it renders. None of this round has been run in Revit.
  • Whether the panel is now too tall. Seven sections in a docked pane is more than it has ever held and none of it has been seen at a real width.
  • Whether the code buttons wrap sensibly. The real model has more codes than the four shown here.
  • How the tick boxes, the buttons, the text boxes and the dropdowns look. They keep the Windows control chrome, which is drawn light on both Revit themes.
  • Whether the font Revit gives the pane has a glyph for the three box characters.
  • Whether the numbers shown are anything like a real model. They are made up to show the shape of the lines.
