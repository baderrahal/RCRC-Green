KPI pane, third round: the template block

This is a mockup drawn by hand from the code in src/RcrcGreen.Revit/Kpi/KpiPanel.cs. It is not a screenshot.

Nothing on this page has been rendered by Revit or by WPF. It cannot show how a docked pane wraps these lines at a real width, whether the list of workbook buttons reads as a list or as a wall, how the folder picker dialog looks, what the real fonts come out as, or whether the two blocks together are taller than the pane and how the scroll feels.

It exists so the layout and the wording can be read before someone spends an install on it. If anyone ever describes it as a screenshot, it has stopped being worth having.

The block, a workbook picked

The scan block from the first round is unchanged at the top and the bottom. The middle is new. The file names and the folder here are invented for the drawing. What a pick would fill is the whole point: a person checks these lines against the annotated workbook before anything is ever written. There is no fill button, because filling waits on the scan report and a control that does nothing is a lie about what the tool can do.
