Drawing Sheet, step 4 rebuilt

This is a mockup drawn by hand from the code in src/RcrcGreen.Revit/DrawingSheetPanel.cs. It is not a screenshot.

Nothing on this page has been rendered by Revit or by WPF. It cannot show how Revit's theme paints a docked pane, what WPF's own chrome does to an editable ComboBox or a RadioButton, whether a card inside a step reads as one thing or as a box inside a box, how two scrolling lists one above the other behave under a real mouse, or what the real fonts and spacing come out as.

It exists so the layout and the wording can be read before someone spends an install on it. If anyone ever describes it as a screenshot, it has stopped being worth having.

What changed

Step 4 used to hold one dropdown of sheets already in the model, to copy, and a table of a number and a name per plot. The first sheet it made came out empty, because the sheet picked to copy had no views on it. A sheet is described here now. The type, the name, the views and how many go per sheet are shared, the number is per plot, and more than one sheet can be described so one run gives a plot its list of drawings and its layout together.

Where the views sit

Worked out in SheetLayout.For in Core from the title block's own width and height, not read off a sheet somebody laid out. One is centred, two sit side by side, four make a two by two grid, and the margin round the outside is the same measurement as the gap down the middle. Reading order, left to right then top to bottom, so views go on in the order they were ticked. Revit counts Y up from the bottom, so the first spot back is the top left one. The rectangles below are drawn to those proportions on a sheet of 841 by 594.
