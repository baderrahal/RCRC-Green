# steps

The worker's notes on this repo, written by Claude Code, merged to main, and read on a phone.
Short lines. One action per step. Every command in a code block.

## Files

- `PROGRESS.md` the one page to start from, at most 60 lines. Read first
- `START.md` the prompt to paste into a new Claude Code session
- `01_next.md` the plan, items numbered F1, F2, in the order they are worked
- `02_questions.md` every question for Bader, numbered, the answer under each
- `03_your_steps.md` what Bader does at the machine, numbered, one action per step
- `log-<task>.md` one entry per round per task, newest at the top: `log-drawing.md`,
  `log-kpi.md`, `log-view-filters.md`, `log-sheet-tool.md`. `log.md` is the older shared log
- `ai-max-state-<task>.md` each task's phase, the file the commit hook asks for
- `latent.md` findings no real input reaches, kept with no fix
- `usage.md` one row per session, its tokens and cost
- The dated files and the `audit-*` and `run-*` files are older rounds' records, kept whole

## How to read it

`PROGRESS.md` is always the latest word on where things stand. Start there, then `01_next.md`.
Read `03_your_steps.md` at the machine that has Revit 2024. Answer `02_questions.md` in any
order.

## Marks used

- `UNKNOWN` could not be found out, and was not guessed
- `LOCAL MACHINE ONLY` needs Revit on the machine
- `F1, F2` an item of the plan in `01_next.md`
- `Q1, Q2` a question in `02_questions.md`
