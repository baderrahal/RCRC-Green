# ai-max state

This file is split by task. Drawing Sheet's state is in `steps/ai-max-state-drawing.md`
and KPI's is in `steps/ai-max-state-kpi.md`. The shared early history, phases 1 to 8 of
the original single session, is at the foot of the Drawing Sheet file, because that
session wrote it. Nothing writes here any more, and the commit hook now asks for the
task's own state file rather than this one. A new task starts
`steps/ai-max-state-<task>.md` on its first round.
